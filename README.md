# Outfit-color-matcher
A smart, ML-powered tool that detects outfit colors and recommends perfect matching bottoms with direct online shopping links.
Outfit Color Matcher

A smart, ML-powered tool that detects the dominant color of a user's top (typed or uploaded) and recommends matching bottom colors along with direct shopping links from Flipkart, Amazon, Meesho, Myntra, and Ajio.

Features:
Detect dominant color from an uploaded image
Accept color names as input
Recommend matching outfit colors
Provide direct online shopping links
Clean and responsive UI for both web and Android versions

Tech Stack:
Python, Flask
HTML, CSS, JavaScript
OpenCV, sklearn
Kotlin (Android app)
